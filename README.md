# 鼻炎用药

给家人在 iPhone 上记幼儿过敏性鼻炎：按医嘱打卡、记症状、对照天气、估算一瓶还能用多久。加到主屏幕后像一个小 App。

记录只存在**打开它的那台手机**里，不会上传到仓库，也不会出现在服务器网页文件里。这不是医疗设备，不能替代医生的医嘱。

请用 **Safari** 打开后再「添加到主屏幕」。不要停在微信内置浏览器里。日常入口用家里自己的网页地址，不要用 GitHub Pages。

## 第一次怎么用

1. 用 Safari 打开家里的用药网页（不要用微信打开）。
2. 点底部分享 → **添加到主屏幕**。
3. 以后从主屏幕图标进入。
4. 打开 **药物** 页：加上正在用的药（药名、每天几次、剂量说明），设好孩子称呼和城市。

口服液（例如西替利嗪）可点 150 / 300 毫升，并填每次用掉多少毫升，用来估算何时换新。鼻喷按喷数填。

## 三页

### 今日

- 看当天天气。降温或下雨会提示「天气变化」。
- 近 7 天：最低温、变天、当天最重症状并排，方便对照「变天是不是更咳」。
- 按医嘱打卡：点「记一次」，可撤销。超过医嘱次数仍能记，会标出来。
- 打开今日时，若还没记满，会写出还缺哪一次（每天两次时按上午/晚上）。不是系统推送，锁屏不会响。
- 每次会记下钟点。点钟点可改成实际用药时间。
- 记流鼻涕、鼻塞、打喷嚏、咳嗽、夜间睡眠（无/轻/中/重），以及整体好转/差不多/加重。
- 若昨天没记满，会出现「去补记」。

### 日历

- 格子按当天最重症状着色；降温或下雨另有标记。
- 点某一天（今天或以前）可补记用药、改钟点，也可补记那天的症状。还没到的日子不能记。

### 药物

- 添加、编辑、暂停、删除药物。
- 填一瓶容量和每次用量后，会显示大约还剩多少、哪天该换新。开了新瓶就点「开了新一瓶」。
- **给医生看**：近两周用药次数对照医嘱、每天最低温/变天/最重症状。可截图，也可复制文字。
- 换机或清缓存前，用「导出备份」保存 JSON；需要时再导入。导入会覆盖这台手机上的现有记录。

## 请记住

- 数据在这台手机的浏览器里。换手机、卸载、或清 Safari 数据，记录可能丢失，请先备份。
- 你在电脑打开同一个网址，看不到她手机里的记录。
- 无网也能打卡；看天气当时需要有网。
- 第一版不做系统提醒、不做小程序、不做登录账号。

## 本机开发

```bash
npm install
npm run dev
```

发版：把 `main` 推到 GitHub，再按 [DEPLOY.md](DEPLOY.md) 在自有服务器更新静态页（路径 `/yao/`）。不要用 GitHub Pages / Vercel / Netlify 当国内日常入口。
